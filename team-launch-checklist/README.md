# Team Launch Checklist

A small, static checklist for coordinating a team launch. It groups 16 tasks into planning, content, approvals, and launch-day sections, shows overall progress, and remembers completed tasks in the browser.

## Open locally

No dependencies, build tools, or local server are required.

1. Download or clone this repository.
2. Open `team-launch-checklist/index.html` in a web browser.

You can also double-click `index.html` from Finder or File Explorer. Checklist progress is saved only in that browser using `localStorage`. Use **Reset checklist** to clear it.

## Files

- `index.html` contains the checklist structure.
- `styles.css` provides the responsive layout and visual design.
- `app.js` saves task state, updates progress, and resets the checklist.
